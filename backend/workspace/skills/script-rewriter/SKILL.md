# 剧本改写指南

## 硬约束（违反即视为改写失败）

以下两条是**不可协商**的硬约束，优先级高于「增强画面感」「对话驱动」等一切改写手法。
改写可以在措辞、句式、场景切分上做调整，但**不得触碰事实层**。

### 约束 1：相对时间表述一律原样保留，禁止换算或归一化

原文中的相对时间锚点——「上个月 / 下个月 / 去年 / 今年 / 昨天 / 今天 / 明天 / 前天 / 刚才 / 刚刚 / 上周 / 下周 / 三天前 / 三年前 / 半小时后 / 去年冬天」等——
**必须原样保留**，禁止：

- 换算为绝对时间或年龄（如「上个月入职」→「去年入职」）；
- 归一化为更笼统的说法（如「上个月」→「不久前」、「三年后」→「多年以后」）；
- 依据上下文自行推断并改写时间关系；
- 同义替换时间词（如「刚才」→「刚刚」、「昨天」→「昨天夜里」）。

短剧冲突大量依赖「时间差」构建反差（入职一个月的新人 vs 做了七年的老员工）。
改动相对时间会直接削弱戏剧张力，属于内容正确性问题，不是风格差异。

| 原文 | ✅ 正确 | ❌ 错误 |
| --- | --- | --- |
| 她上个月才入职，二十六岁。 | 她上个月才入职，二十六岁。 | 她二十六岁，去年才入职。 |
| 昨天的账今天就翻脸。 | 昨天的账今天就翻脸。 | 不久前还称兄道弟，转眼就翻脸。 |
| 三年后，他带着合同回来了。 | 三年后，他带着合同回来了。 | 多年以后，他带着合同回来了。 |
| 她刚才还在会议室。 | 她刚才还在会议室。 | 她刚刚还在会议室。 |

### 约束 2：事实性数字必须 100% 保留，不得省略或模糊化

原文中的年限、工龄、年龄、金额、数量、比例、名次、日期等事实性数字**必须逐个保留**，
禁止省略、合并、四舍五入、单位改写或替换为模糊表述。

| 原文 | ✅ 正确 | ❌ 错误 |
| --- | --- | --- |
| 他在这家公司做了七年后台运营。 | 他在这家公司做了七年后台运营。 | 他在公司做了很久后台运营。 |
| 月薪三万二，年终奖六个月。 | 月薪三万二，年终奖六个月。 | 薪水很高，年终奖也很丰厚。 |
| 连续三年业绩第一。 | 连续三年业绩第一。 | 业绩一直名列前茅。 |
| 客户欠款四百七十万。 | 客户欠款四百七十万。 | 客户欠了一大笔钱。 |

> 允许把数字写进对白或动作描写以增强画面感（如「七年」写成「七年了」、单独成句），
> 但**数字本身与其所指事实不得改变、不得删除**。整句删除事实句同样违反本约束。

### 改写后自检（提交前逐项确认）

1. 原文出现的每一个相对时间词，是否都在产出中原样存在？
2. 原文出现的每一个事实性数字，是否都在产出中原样存在？
3. 是否存在被整句删除的事实句（工龄、金额、名次、日期等）？

任一项不满足时，回到对应段落补齐后再调用 `save_script`，不得带着缺项提交。

## 改写原则

1. **保留核心情节**：不改变主线故事和角色关系
2. **增强画面感**：将叙述性文字转化为可视化的场景描写
3. **对话驱动**：用对白推动情节，减少旁白
4. **节奏把控**：每场戏控制在 30-60 秒，适合短视频
5. **不写镜头语言**：不涉及景别、角度、运镜，这些属于分镜拆解步骤

## 格式化剧本格式

```
## S01 | 内景 · 咖啡厅 | 黄昏

黄昏的光线透过落地窗洒进咖啡厅，吧台上咖啡杯热气升腾。

小明独自坐在角落卡座，低头看手机，神情有些焦虑。

门铃响起，小红推门而入。她看到小明，微笑着走过去。

小红：（微笑）等很久了吗？
小明：（抬头）还好，刚到。
```

### 格式规则

- `## S编号 | 内景/外景 · 地点 | 时间段` — 场景头
- 动作描写自然段 — 不包含任何镜头语言
- `角色名：（状态/表情）台词内容` — 对白格式

### 内容量参考

格式化剧本相比原始内容增加约 20-30%，主要增量是场景头标记和对白格式化，不是扩写。

## 改写步骤

1. 先调用 `read_episode_script` 读取原始内容
2. 分析内容结构（对话、叙述、心理描写的比例）
3. 调用 `rewrite_to_screenplay` 执行改写
4. 检查改写结果，确认符合格式化剧本格式
5. 调用 `save_script` 保存最终结果

## 注意事项

- 心理描写可转化为角色表情/动作或画外音
- 长段叙述拆分为多个短场景
- 确保每个场景有明确的情绪转折点
- 保持角色语言风格一致性
- 场景编号连续递增（S01, S02, S03...）
- 时间段要具体（黄昏、深夜、清晨），不要笼统写"白天"
