# 夜市回声

## Logline

失踪父亲留下的一段夜市录音，把林夏带回十年前那场无人解释的停电事故。

## Drama Bible

### 世界观

故事发生在临江市旧城夜市。每逢农历十五，夜市会在 23:17 短暂断电；停电期间的录音会出现无法解释的第二条人声。

### 主线冲突与结局承诺

林夏追查父亲失踪的真相，同时必须决定是否公开会伤害无辜摊主的证据。第一季结尾确认父亲曾主动隐藏关键录音，但留下了继续调查的线索。

### 分集关系

- 第 1 集：发现录音并确认断电规律。
- 第 2 集：找到旧广播室，听见父亲留下的回应。
