# 第 1 集：灯灭之前

## Objective

林夏确认父亲的录音与旧城夜市断电规律有关。

## Hook

停电后的录音里出现了林夏从未听过的第二条人声。

## Content

林夏在雨后的夜市找到父亲留下的旧录音笔。周叔不愿解释那段杂音，只提醒她记住每月十五日的 23:17。远处的灯牌同时熄灭，录音笔却重新亮起，播放出一声陌生的“别去广播室”。
